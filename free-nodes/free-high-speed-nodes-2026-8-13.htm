二、准备工作：安装与基础设置

首次启动小火箭时，应用会请求网络访问权限——务必点击"允许"，这是代理功能正常工作的基础。接下来建议进行以下基础设置：

  • 网络模式选择：小火箭提供"全局模式"（所有流量都通过代理）和"分应用模式"（可指定特定应用使用代理）。根据你的需求选择合适模式，通常建议先试用全局模式测试连接。
  • 基础安全设置：在设置中开启"加密DNS"和"阻止跟踪器"等选项，增强隐私保护能力。
  • 通知权限：允许小火箭发送连接状态通知，便于实时监控代理工作情况。

三、详细教程：两种方式导入Vmess链接

方法一：手动输入配置（适合学习理解）

虽然粘贴链接更便捷，但了解手动配置有助于你深入理解各参数的意义：

  1. 打开小火箭，点击底部"配置"标签
  2. 选择右上角"+"号，点击"添加配置"
  3. 在类型中选择"Vmess"
  4. 依次填写：
    • 地址：服务器域名或IP地址
    • 端口：通常是443或其它指定端口
    • 用户ID：由服务商提供的UUID字符串
    • 额外ID：多数情况下填0
    • 加密方式：一般为"auto"或"none"
    • 传输协议：可选择tcp、ws、kcp等
  5. 完成后点击"保存"，配置将出现在列表中

方法二：剪贴板导入（推荐日常使用）

这是最常用的方式，只需几秒钟：

  1. 从你的服务商处复制完整的Vmess链接（通常以"vmess://"开头）
  2. 打开小火箭应用，停留主界面
  3. 应用会自动检测剪贴板中的代理链接并弹出提示
  4. 点击"导入"，系统会自动解析所有参数
  5. 确认信息无误后点击"保存"

专业提示：如果链接未能自动识别，可进入"配置"页面，点击右上角"+"，选择"从剪贴板导入"。

FAQ

QuantumultX 支持按端口进行流量分流吗？
支持。用户可以根据端口号将不同应用流量分流到指定节点。例如游戏走低延迟节点，浏览网页走普通节点，实现精准流量管理和优化网络访问速度。
Surfboard 的配置文件可以与 Clash 通用吗？
Surfboard 基于 Clash 核心，因此支持大部分 YAML 配置文件，但部分字段如 rule-provider、external-controller 等可能不兼容。建议使用订阅转换工具将 Clash 文件转换为 Surfboard 兼容格式导入。
如何在 Nginx 上为 Vmess/WS 配置反向代理与 TLS？
在 Nginx 中配置 HTTPS 站点并将特定路径（如 /ray）反向代理到 V2Ray 的 WebSocket 端口，确保 proxy_set_header 设置正确（Host、X-Real-IP 等）。同时使用 certbot 获取并自动续期 TLS 证书以维护安全。
Matsuri 如何结合 Xray 内核实现多协议支持？
Matsuri 可加载 Xray 核心，通过配置多 inbound/outbound 模块实现 VMess、VLess、Trojan 等协议共存。用户可在单一服务端配置文件中同时支持多客户端访问，便于统一管理。
WinXray 如何保证视频流畅播放？
WinXray 会结合延迟检测和策略组选择最佳节点转发视频流量。通过自动切换低延迟节点，可保证在线视频播放顺畅，减少卡顿和缓冲，提高整体体验。
Nekoray 支持节点批量更新吗？
支持。Nekoray 可通过订阅 URL 批量下载最新节点并替换旧节点。结合定时更新功能，可保持节点列表最新，减少手动维护和配置工作。
V2Ray 配置中如何避免端口扫描暴露服务？
避免使用常见端口（如 80、443）直接暴露 V2Ray 服务；若必须使用 443，建议通过 Web 服务器反代或使用 CDN；同时启用 fail2ban 与 iptables 限制异常连接频率，减少被扫描发现的风险。
Hysteria2 多路复用对高频连接的优势？
多路复用可让多个短连接共享同一通道，减少握手和加密开销，提高吞吐量。适合高频短连接场景，如即时通讯和游戏，保证流量快速、稳定传输。
Hysteria2 协议的主要特点是什么？
Hysteria2 是新一代基于 QUIC 的高速代理协议，支持自适应拥塞控制和零 RTT 连接。相比传统 TCP 协议，它能在高延迟或丢包环境下保持稳定速度，特别适合跨境访问或实时传输场景。
Clash 如何配置策略组优先节点？
在 Clash 中，用户可以通过策略组设置节点优先级，优先使用延迟低、稳定性高的节点。结合规则文件，可以根据域名或 IP 自动选择最优节点，实现更高效的网络访问体验。
